The single sentence a house cat would say in the five seconds after sweeping a glass off the table. No apology, no confession — the cat's own defence: the glass watched it knock the plant over yesterday, so it removed the only witness before it could talk. Pure cat logic — self-preservation, zero remorse — and a fresh angle in a field drowned in sunbeam-eviction and gravity lines.

## Run it

```sh
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
